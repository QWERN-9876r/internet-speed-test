# Проверка скорости скачивания

Консольный скрипт на Node.js и TypeScript полностью скачивает указанный ресурс
несколько раз параллельно. По умолчанию выполняются 10 измерений и один отдельный
прогревочный запрос. В итогах показываются среднее, медианное, минимальное и
максимальное время ответа, общий объём и совокупная скорость параллельной загрузки.

Объём и скорость указаны в **МиБ** (1 МиБ = 1 048 576 байт) и **МиБ/с**.
Учитываются байты тела ответа, видимые Node.js `fetch`, без HTTP-заголовков;
ответы с gzip/Brotli могут учитываться после распаковки. Скорость отдельного
запроса — его объём, делённый на время загрузки. Скорость пакета — сумма объёмов
успешных измерений, делённая на реальное время выполнения параллельного пакета.
Это совокупная пропускная способность, а не скорость одного соединения.

## Требования

- Node.js 20 или новее
- npm

## Запуск

```bash
npm install
npm start -- https://qwern9876r.ru/img/photo-948a13ea-600.avif
```

Параметры можно менять:

```bash
npm start -- https://example.com/image.jpg --count 20 --warmup 2 --timeout 10000
```

| Параметр | По умолчанию | Описание |
| --- | ---: | --- |
| `--count N` | `10` | Число параллельных измерений (1–1000) |
| `--warmup N` | `1` | Число последовательных прогревочных запросов, не входящих в статистику (0–100) |
| `--timeout MS` | `30000` | Тайм-аут каждого запроса в миллисекундах (1–600000) |
| `--cache-bust` | выключен | Добавлять уникальный параметр к URL каждого запроса |
| `--help` | — | Показать справку |

`--cache-bust` помогает выявить кэширование на CDN, но меняет URL и может сделать
недействительной подписанную ссылку. Без него каждый запрос всё равно отправляет
`Cache-Control: no-cache, no-store` и `Pragma: no-cache`. Если сервер или CDN
сообщает о кэше, скрипт показывает доступные заголовки `Age`, `Cache-Status`,
`CF-Cache-Status`, `X-Cache` и `X-Vercel-Cache`. Отсутствие таких заголовков не
гарантирует отсутствие кэша.

Для проверки типов:

```bash
npm run typecheck
```

Для запуска тестов:

```bash
npm test
```

Скрипт принимает абсолютный URL с протоколом `http://` или `https://`. При сбое
одного из запросов он сохраняет и выводит успешные результаты, а завершает работу
с ненулевым кодом.

В терминале вывод оформляется цветом; для отключения цветов установите
переменную окружения `NO_COLOR`.
