# Проверка скорости скачивания

Консольный скрипт на Node.js и TypeScript скачивает указанный ресурс 10 раз
последовательно и полностью считывает каждый ответ. В конце он показывает
среднее время одного запроса, суммарный объём скачанных данных и среднюю скорость
скачивания за всю серию.

Объём и скорость указаны в **МиБ** (1 МиБ = 1 048 576 байт) и **МиБ/с**.
Учитываются байты тела ответа, без HTTP-заголовков. Скорость рассчитывается как
общий объём за полное время серии запросов.

## Требования

- Node.js 20 или новее
- npm

## Запуск

```bash
npm install
npm start -- https://example.com/image.jpg
```

Для проверки типов:

```bash
npm run typecheck
```

Скрипт принимает абсолютный URL с протоколом `http://` или `https://`.
Тайм-аут каждого запроса — 30 секунд. Если запрос завершился ошибкой или сервер
вернул HTTP-статус вне диапазона 200–299, скрипт выводит сообщение об ошибке и
завершается с ненулевым кодом.

В терминале вывод оформляется цветом; для отключения цветов установите
переменную окружения `NO_COLOR`.
